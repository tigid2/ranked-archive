# 판단 규칙

피드백을 쓸 때 따르는 규칙이에요. 규칙마다 근거, 지지 횟수(실제 판에서 맞는 걸로 확인된 횟수), 마지막으로 확인한 패치를 적어요.
플래티넘 티어에 따른 시사점은 있을 때만 "플래티넘:"으로 덧붙여요.
새 규칙은 `candidates.md`에 먼저 넣고, 사용자가 고르면 여기로 옮겨요.

## 글쓰기
- "데스"는 숫자를 셀 때만 써요. 나머지는 "죽음/죽었어요"로 써요.
- 가운뎃점(·) 대신 "/"나 쉼표를 써요.
- 영어 보조 라벨, 로고, 바닥글, "데이터로 알 수 없어요" 같은 말은 넣지 않아요. 글자 아이콘은 그림 아이콘으로 바꿔요.
- 메모에는 데이터로 알 수 없는 것만 적어요.
- 근거: 사용자가 정함 / 확인: 2026-11

## 리포트 구성
- 자체 점수, S/A 등급, 스킬 순서 표는 넣지 않아요.
- 시야 섹션은 서폿/미드일 때만 넣어요.
- 닉네임은 보여 주지 않고 티어/LP/연승/최근 모스트를 보여 줘요.
- 게임 중 기록이 없던 판의 스펠/체력/골드는 "기록 없음"으로 표시하고, 실제 기록으로 저장하지 않아요.
- 근거: 사용자가 정함 / 확인: 2026-11
