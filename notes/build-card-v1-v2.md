# 06 빌드 비교 칸: 기존안(v1)과 개선 시안(v2) — 11-16

사용자가 시각적 위계를 더 주고 싶지만 디자인을 망칠까 걱정해서, 기존안을 기록해 두고 개선안을 따로 만들었어요. 본 리포트에는 아직 v1만 나와요.

## v1 (지금 본 리포트, `web/src/sections/Extra.jsx`의 `BuildCard`)
- 스크린샷: `notes/img/build-v1.png` (징크스 KR_8460619175)
- 표 한 장: 슬롯 / 내 선택 / 완성 시간(평균 N분대, 늦음·빠름) / 선택률(몇 번째로 많음) / 승률 / 다른 선택 2개
- 아래: 구매 순서, 룬, 소환사 주문, 상대 팀 피해 구성(`BuildExtras`, v2도 같이 씀)
- 아쉬운 점: 모든 숫자가 같은 무게라서 "그래서 이 판 빌드는 어땠는지"가 바로 안 보여요.

## v2 (개선 시안, `web/src/sections/BuildV2.jsx`의 `BuildCardV2`)
- 맨 위 두 칸 결론: "고른 아이템"(흔한 선택이었나) / "완성 속도"(평균보다 빨랐나). 규칙으로 만드는 문장이라 토큰 0.
- 선택이 정석인데 늦었으면 한 줄 안내: 골드 버는 속도를 02 흐름의 CS·골드 차이에서 확인.
- 완성 시간을 시간 막대로: 회색 칸 = 같은 챔피언 평균 완성 구간(N분대), 점 = 내 완성 시점, 사이 선 = 차이(늦으면 다크, 빠르면 민트).
- 선택률·승률은 오른쪽에 작게, 다른 선택은 "다른 선택 보기"로 접음.
- 보는 법: `single.py`로 만든 html의 `<div id="root"></div>` 뒤에 `<script>window.__BUILD_V2__=true</script>`를 넣으면 v1 아래에 v2가 같이 나와요.
- 사용자가 v2를 고르면: `Build.jsx`에서 `BuildCard`를 `BuildCardV2`로 바꾸고 제목의 "· 개선 시안"을 빼요.
